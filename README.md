# Sistema de Turnos para una Clínica

Aplicación web full-stack para la gestión de turnos de una clínica, desarrollada como proyecto de portfolio.

## Stack

- **Frontend:** Angular, TypeScript, Tailwind CSS, DaisyUI, PrimeNG
- **Backend:** NestJS, TypeScript, Prisma ORM, PostgreSQL
- **Autenticación:** JWT
